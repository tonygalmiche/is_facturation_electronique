# is_facturation_electronique

Module Odoo 18 développé par **InfoSaône** pour la mise en conformité avec la réforme française de la **facturation électronique** (obligation B2B à partir de septembre 2026).

Le but de ce module est de **documenter l'installation et les modules mis en place** pour cette mise en conformité sur Odoo Community : il s'appuie sur l'implémentation communautaire d'Akretion (`l10n_fr_einvoicing`) et ses dépendances (SIRET, nomenclatures UNECE, Saxon Server pour la validation Schematron des factures Factur-X/UBL).

## Documentation

Toute la documentation détaillée (modules, dépendances, installation, configuration) se trouve dans [`documentation/`](./documentation/README.md).
